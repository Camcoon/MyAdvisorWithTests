2. Project Description
MyAdvisor is a coursework prototype for Student–Advisor academic planning. It brings degree progress,
prerequisite-aware course selection and plan decisions into connected workspaces, addressing the difficulty of
reconciling completed work, current courses and proposed semester choices across separate records.
Workflow / user
Purpose and implemented behavior
WF1: Track Degree Progress —
Student
View completed, in-progress and remaining credits; overall progress;
requirement categories; recent academic activity.
WF2: Plan Semester Course
Selections — Student
Search/filter the catalogue, inspect eligibility, review and submit
selections, read feedback, revise returned plans, remove permitted
courses and cancel/replace plans.
WF3: Review and Approve
Course Plans — Advisor
Inspect the shared Pending queue and Student/course details; Approve,
Reject or Request Changes, with optional feedback.
Students use Home, Degree Progress, Plan Courses, Messages and Profile. Advisors use their own Home/Profile
and Advisor Review. Student identity comes from the authenticated account; Advisor decisions update a plan’s
status, reviewer and feedback. Semesters use the nine fixed Year 1–3 / semester 1–3 options, with semester 3
designated summer.
Technology
Role
Python / FastAPI / Pydantic
HTTP application, request validation and JSON APIs.
SQLModel / SQLAlchemy / SQLite
Models, repository persistence and isolated local tests. The Render
blueprint targets PostgreSQL; no production database test is claimed.
Jinja2 / Bootstrap / AdminLTE /
JavaScript
Rendered Student/Advisor pages and selection/review interactions.
pwdlib / PyJWT / signed cookies
Password verification, signed login token, current-role and ownership
checks.
pytest / TestClient / mocks / Postman
Isolated unit decisions, integrated HTTP/database checks and
automated API collection.
Assignment 2 scope. Extends the Assignment 1 workflows with explicit JSON API contracts, unit/integration
plans and pytest implementations, a 90-request Postman collection, manual UAT specifications and execution
records, screenshots and traceability. This is demonstration data, not an authoritative UWI curriculum: the
93-credit degree and 120-credit category total remain inconsistent (F05).
Source: docs/report.md; app/models; app/routers; docs/assignment2/api.md.
